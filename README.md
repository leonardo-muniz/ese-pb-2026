# :chart_with_upwards_trend: Projeto de Bloco: Engenharia de Softwares Escaláveis [26E2-26E3]

Repositório criado para a disciplina de **Projeto de Bloco em Engenharia de Softwares Escaláveis**, demonstrando a evolução de uma aplicação monólita simples em **Java** e **Spring Boot**, sua evolução para persistência de dados, sua transformação em microsserviços, implementação de uma arquitetura orientada a eventos e finalizando com implementação completa com o Docker, Kubernetes, CI/CD do GitHub e testes unitários e de integração entre os microsserviços.
